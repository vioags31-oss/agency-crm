# 🔄 Автоматичне комітування

Цей проект має вбудований скрипт для автоматичного комітування змін на GitHub!

## 🚀 Як використовувати

### 1. **Встановити залежності** (один раз)
```bash
npm install
```

### 2. **Запустити dev + автокоміт разом**
```bash
npm run dev:watch
```

Це запустить:
- Next.js dev сервер на `http://localhost:3000`
- Файл-watcher який автоматично коммітить зміни

### 3. **Або запустити тільки автокоміт** (якщо dev вже работает)
```bash
npm run watch-and-commit
```

## 📝 Як це працює

1. Скрипт слідкує за змінами в папці `app/`
2. Коли файл змінюється - чекає 2 секунди
3. Автоматично:
   - `git add -A` - додає всі зміни
   - `git commit -m "🔄 Auto-commit: [час]"` - коммітить
   - Намагається `git push origin main`

## ⚙️ Конфігурація

Змінювати можна в `watch-and-commit.js`:

```javascript
const DEBOUNCE_TIME = 2000; // Затримка перед коммітом (мс)
const WATCH_DIR = path.join(__dirname, 'app'); // Яка папка слідкувати
```

## 🚫 Що ігнорується

Автоматично ігнорує папки:
- `node_modules`
- `.next`
- `.git`
- `dist`
- `.vercel`

## 🐛 Якщо щось піде не так

Скрипт просто пропустить коміт якщо:
- Нема змін для коміту
- Git не ініціалізований
- Якась помилка в команді

Можна переглянути логи в консолі!

## 💡 Поради

- Каждый коміт матиме timestamp: `🔄 Auto-commit: 26.05.2026, 22:15:30`
- Git push може не работати з bash (мережа обмежена), але локально все коммітиться
- Для нормального push на GitHub - запустити командою локально на комп'ютері

## 📦 Залежності

```json
{
  "concurrently": "^8.2.2"
}
```

`concurrently` - дозволяє запустити dev та watch разом одною командою
